# Vitals Android brand resources

Generated by `node scripts/brand/android.mjs` (also run by `scripts/brand/generate.mjs`) from
`public/brand/mark.svg` and `mark-small.svg`. Do not edit the files here by hand: change the source SVG and
regenerate.

## Wiring (for the Capacitor app)

1. Add `apps/android/brand/res` as a res folder of the app module (or copy its contents into
   `app/src/main/res`), e.g. in `app/build.gradle`:

   ```groovy
   android { sourceSets { main { res.srcDirs += ['../../brand/res'] } } }
   ```

   Remove Capacitor's default `mipmap-*/ic_launcher*` files and `mipmap-anydpi-v26/ic_launcher*.xml` so these win.

2. `AndroidManifest.xml`, on `<application>`:

   ```xml
   android:icon="@mipmap/ic_launcher"
   android:roundIcon="@mipmap/ic_launcher_round"
   ```

3. Splash (Android 12+, `values-v31` theme of the launch activity):

   ```xml
   <item name="android:windowSplashScreenBackground">@color/vitals_splash_background</item>
   <item name="android:windowSplashScreenAnimatedIcon">@drawable/vitals_splash_animated</item>
   <item name="android:windowSplashScreenAnimationDuration">700</item>
   ```

   The ring draws on in 500 ms, the dot pops in from 420 ms and settles by
   640 ms; it plays once. Light and night grounds come from
   `values(-night)/vitals_brand_colors.xml`. With animations off Android shows the finished mark.

4. Notifications: `setSmallIcon(R.drawable.ic_stat_vitals)` (white only; Android tints it).

## Files

- `res/mipmap-anydpi-v26/ic_launcher.xml`, `ic_launcher_round.xml`: adaptive icon (background, foreground,
  monochrome for themed icons). The launcher ground stays light in night mode.
- `res/drawable/vitals_launcher_{foreground,background,monochrome}.xml`
- `res/drawable/vitals_splash_mark.xml`, `vitals_splash_animated.xml`, `res/animator/vitals_splash_*.xml`,
  `res/interpolator/vitals_splash_overshoot.xml`
- `res/drawable/ic_stat_vitals.xml`
- `res/values/vitals_brand_colors.xml`, `res/values-night/vitals_brand_colors.xml`
- `playstore-512.png`: Play Store icon (512 px, full bleed; Play applies its own corner mask).
- `preview/launcher-*.png`: how the adaptive icon looks through common launcher masks (documentation only).
