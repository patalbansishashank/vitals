## For other areas

- `docs/COMPANION.md:134` says a SIWC 429 `subscription_sharing_usage_limit_exceeded` reaches the Coach as "Your ChatGPT plan has reached its usage limit for now … Settings › Usage". The Coach maps every `quota` error to `COACH_TEXT.outOfCredit` ("Your provider says you're out of credit (or at your plan's limit)…"), so the proxy's own words are never shown. Either correct the doc, or add a SIWC-specific line in `errorFor` (`src/ai/coach/adapter.ts`).

## Verified fine

- SSE parser: CRLF and LF line ends, a CR split across chunks, multi-byte characters split across chunks, comment keep-alives, and a final event without a blank line. Abort cancels the reader.
- Retry: full jitter, capped at 30 s, 4 tries. A readable `retry-after` wins but is capped. Sleeps are abortable, and there is no retry after an abort or a non-retryable error. Only the request phase is retried, so output is never duplicated mid-stream.
- Error classification: 401 and 403 map to auth (or quota when the body says so). A 429 with `insufficient_quota` or `usage_limit` maps to quota (not retried). 529 or "overloaded" is retryable. A first-contact `TypeError` maps to cors. `NetBlockedError` messages are plain.
- Secrets: `ProviderError` redacts key-like strings and bearer tokens. Companion presets send `authHeader:'none'` and an empty key from the page (both in `createChatModel` and in the probe path). I found no `console.*` calls in the area outside tests. Keys sit in the KeyVault (IndexedDB, AES-wrapped), never in localStorage.
- OpenAI Responses body: `stream:true`, `store:false`, and `include:['reasoning.encrypted_content']` when reasoning is on. The tool namespace carries a `description`. Function calls are assembled by `output_index`, `response.incomplete` maps to length or refusal, and `response.failed` and `error` throw typed errors. Models are listed from `{data:[{id}]}`; the proxy translates the ChatGPT backend's `{models:[{slug}]}`.
- Chat completions: index-less and reused-index tool fragments, `<think>` split across chunks, OpenRouter `reasoning_details` merge, the Groq `x_groq.usage`, the Mistral 9-character ids (deterministic, pairs stay matched), and a trailing usage chunk read after `finish_reason`.
- Anthropic: consecutive tool results are merged into one user turn. There are at most 4 `cache_control` breakpoints. Thinking blocks are echoed only to the same preset and model, as shallow copies. `tool_choice` is only `auto` or `none`. Usage sums cache reads and writes into input.
- Coach loop: the step limit ends with a no-tools step. Dangling tool calls are closed off after a stop. Per-turn caps (20 calls, 5 writes, 1 destructive) hold. Reads run in parallel, writes in order. The spend cap is checked before each message.
- Prompt injection: the model cannot run destructive commands. They become a card that needs the person's typed confirmation (`bus.ts` `consumeConfirmation`). Edits go dry-run → proposal → apply as the user. `safety.*` loosening is blocked. Commands not on the AI surface resolve as `excluded`. Lab report rows reach only the card; the model gets counts.
- NaN and Infinity are rejected by the number type check in `validate`, and by `num()` in the model-JSON readers.
