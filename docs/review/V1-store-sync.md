## Verified fine (pass 2 need not redo)

- **Export → erase → import (replace) → export:** `stores` are deep-equal and collection **bodies** are byte-equal; only `_rev` changes, as expected because an import is a new write. Checked with a temporary test over `vitals.settings` + `vitals.body` and the existing `documents.test.ts` round trip.
- **Erase coverage:** `vitals-docs` (closed first by `idbBackend.erase`), `vitals-projections`, `vitals-sync` (the vault opens and closes per call, `clear` removes config and secret), `vitals-blobs` (bytes in OPFS deleted one by one by `ChunkStore.erase`, index cleared), Evolu's OPFS `.vitals-*` directories (`deleteEvoluData`, or `eraseLocal` while attached), `vitals.*` / `lumen.*` / `vitals-*` localStorage keys. Service-worker caches hold only hashed static assets and the Evolu runtime (`vite.config.ts` `runtimeCaching` is same-origin, Evolu files only), with no user data. sessionStorage holds only the QA flag.
- **Key handling:** the owner secret is stored only wrapped (AES-GCM under a non-extractable device key in IndexedDB). HKDF extract/expand matches RFC 5869 (counter from 1, truncated last block). No `console.*` in the area prints secrets, words, bearers or document bodies; logs name `col/id` only.
- **Pairing parsing:** 24-word check, BIP39 checksum, base64url alphabet check, 32-byte length check, version gate, http allowed only for loopback (`[::1]` included), query and fragment stripped (now covered by `src/sync/pairing.test.ts`).
- **Scheduler:** rounds never overlap; a trigger during a round queues one more; the heartbeat runs only while visible; `stop()` clears all timers; a stopped scheduler arms no retry.
- **Document store transactions:** serialised through `queue.then(run, run)`; a failing transaction does not block the next; append/immutable rules hold inside the buffered transaction; `current()` reads its own pending writes.
- **Migrations on read:** run only when `_schema < target`; the next write stores the target schema (existing test). Documents from a newer schema pass through unchanged.
- **Boot reconcile:** documents vs boot cache compare `_updated` with the mirror stamp, and both come from this device's clock. Remote documents reach the projection through `b.apply`, which rewrites the mirror with a fresh stamp, so clock skew between devices cannot make a stale boot cache win.
- **Zustand selectors:** no selector in `src/` returns a fresh array or object without `useShallow` (zustand 5 would loop). The one `.map` selector joins to a string.
- **Evolu adapter:** own-write echoes are matched by device and content marker, so a newer queued local write is not flickered back; in-flight entries expire after 10 s and are rechecked; size limits are checked before anything is queued (batch stays atomic).
- **Chunk store:** eviction only drops uploaded chunks and never on an unpaired device; uploads skip chunks erased mid-flight; ids carry the content hash, so re-putting an id never needs a re-upload.
